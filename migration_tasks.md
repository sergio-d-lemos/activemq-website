## Architecture Decisions

### Release Pages: Reusable React Component

Each Classic release page will use a shared `ClassicRelease` React component. The structure:

```
src/
  components/
    ClassicRelease/
      index.tsx          # Reusable release page component
  data/
    classicReleases.ts   # All release metadata
    currentReleases.ts   # Current release stream prefixes
  pages/
    components/
      classic/
        download/
          index.tsx      # Download landing page (summary table + current releases)
          classic-05-00-00.tsx   # Individual release pages
          classic-05-01-00.tsx
          ...
          classic-06-02-06.tsx
```

The `ClassicRelease` component handles:
- "Older release" warning banner (if not current)
- Custom release content (passed as children)
- Binary distribution download table (current uses `closer.cgi`, older uses `archive.apache.org`)
- Java compatibility display
- Download verification instructions
- Maven dependency snippet
- Source distribution download table
- Changelog/release notes link
- Link to previous release

### URL Preservation

Original URLs → Docusaurus URLs:
- `/components/classic/download/classic-XX-YY-ZZ` → `/components/classic/download/classic-XX-YY-ZZ`
- `/components/classic/documentation/page-name` → `/components/classic/documentation/page-name`
- `/news/article-name` → `/news/article-name`
- `/contact`, `/contributing`, etc. → same paths

### What's Deferred (CMS & NMS)

- `components/cms/` (17,707 files)
- `components/nms/` (1,122 files)
- `_cms_releases/` (52 files)
- `_nms_*_releases/` (~35 files)

These will be added in a future migration phase.
